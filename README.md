Day 32 – Train-Test Split Using Scikit-learn

Project Description

This project demonstrates how to split a machine learning dataset into training and testing datasets using Scikit-learn.

Objective

To understand why datasets are divided into training and testing sets and how this helps evaluate machine learning models.

Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

Dataset

Iris Dataset (150 samples and 4 features).

Implementation

- Loaded the Iris dataset.
- Separated feature and target variables.
- Split the dataset into 80% training data and 20% testing data.
- Used "train_test_split()" from Scikit-learn.
- Set "random_state=42" for reproducibility.
- Displayed the shapes of training and testing datasets.

Output

- Training Features: (120, 4)
- Testing Features: (30, 4)
- Training Target: (120,)
- Testing Target: (30,)

Learning Outcome

Learned how to divide datasets into training and testing subsets and understood the importance of testing data in machine learning.

Conclusion

Successfully completed Day 32 by performing an 80/20 train-test split on the Iris dataset using Scikit-learn.
